Scope: this model was trained on potato leaves only, and knows exactly three categories: early blight, late blight, and healthy. Give it a tomato leaf, a hand, or a photograph of a wall and it will still return one of those three labels with a confidence attached, because a softmax over three classes has nowhere else to go. Read the confidence as "how strongly this resembles one of the three classes I know", not as a diagnosis.

How to read the heatmap

Red marks the regions that pushed the score for the predicted class up the most; blue marks regions that did not contribute. It answers "what was the model looking at", which is not the same question as "where is the diseased tissue". The map is computed at 7×7 and stretched over the image, so it shows roughly which part of the leaf mattered, not a lesion outline.

A heatmap sitting on the background rather than the leaf is worth noticing: it usually means the prediction leaned on something other than the plant.

What this is

A MobileNetV3-Small backbone, pretrained on ImageNet and fine-tuned on the potato subset of the PlantVillage dataset. The classification head is a single linear layer on top of global average pooling, which is what lets this page reproduce Grad-CAM exactly without running a backward pass: the channel weights Grad-CAM would derive from gradients are, for this architecture, the classifier weights themselves.

That equivalence is verified numerically in the repository rather than asserted — the browser's heatmap is compared against a reference autograd implementation over test images, and the exported ONNX model is compared against PyTorch.
